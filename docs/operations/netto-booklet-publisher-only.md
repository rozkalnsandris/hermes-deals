Publitas REST v1 explicitly defines product hotspots by publisher `hotspot.id`, `products[].id` and normalized **spread** coordinates, and a product-detail endpoint by publisher product ID. Product details are publisher content, **not** proof of a Hermes deal, store SKU, current price or price-history relationship. This change renders **only that publisher detail** in a same-page dialog, never a merchant website deeplink, add-to-list action, or inferred Hermes product. See https://developers.publitas.com/docs/rest-v1.html and https://support.publitas.com/adding-hotspots-to-your-publication.

The optional layer reads only the captured receipt and source JSON files; no network, DB write, Review update or collector. Only receipt-indexed SHA256-matching product files may contribute titles/descriptions.
